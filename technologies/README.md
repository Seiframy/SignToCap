# Technologies

[Open the Live ASL Captions Capstone Decision Report](Live%20ASL%20Captions%20Capstone%20Decision%20Report.pdf) (PDF). The report compares translation models, commercial APIs, and caption delivery in Zoom, Google Meet, and Microsoft Teams. It includes both research diagrams, a six-week plan for four teammates, and tests for caption accuracy and delay.

## First prototype

Use one camera to capture short American Sign Language (ASL) messages. Test Meta SONAR ASL first and Uni-Sign as a second local option. Show the English captions on a private web page that people can open alongside their meeting. Test Zoom first for built-in captions.

ASL Citizen contains clips of single signs. It can help test sign recognition. Sentence translation needs a model that reads signs in context. The team still needs to measure accuracy and delay on meeting clips.
